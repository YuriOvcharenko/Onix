Kropp Fitness - веб-сайт фітнес-центру

Сучасний лендинг для фітнес-студії, створений як частина навчального завдання для компанії Onix-Systems. Проєкт демонструє навички верстки, архітектури React-компонентів та розгортання на GitHub Pages.

Щоб запустити цей проєкт на своєму комп'ютері, виконайте наступні кроки:

1. Клонування репозиторію
```
git clone https://github.com/YuriOvcharenko/Onix.git
cd Onix
```
2. Встановлення залежностей

Переконайтеся, що у вас встановлено Node.js. Виконайте команду:
```
npm install
```
3. Запуск у режимі розробки

Запустіть локальний сервер:
```
npm run dev
```
Після цього відкрийте посилання http://localhost:5173 у вашому браузері.

Збірка та деплой

Для створення оптимізованої папки dist:
```
npm run build
```

Проєкт налаштований на автоматичний деплой за допомогою пакета gh-pages:
```
npm run deploy
```
